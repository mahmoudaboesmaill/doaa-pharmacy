صيدلية د/ دعاء أحمد كمال - صفحات NFC والموقع الرسمي
===================================================

الملفات ومحتوياتها:
------------------
1) index.html    = البوابة الرئيسية (تجمع بين خياري التواصل والدفع + زر طلب الروشتة السريع)
2) contact.html  = صفحة التواصل، طلب الأدوية، وحفظ جهة الاتصال
3) payment.html  = صفحة الدفع والتحويل الإلكتروني (InstaPay ومحافظ الكاش)
4) settings.js   = ملف البيانات والإعدادات (الأرقام، العناوين، الروابط)
5) style.css     = ملف التصميم والأنماط الموحد لجميع الصفحات
6) logo.jpg      = الشعار الرسمي للصيدلية

كيف تعدّل بيانات الصيدلية؟
-------------------------
افتح settings.js بأي محرر نصوص (مثل Notepad أو VS Code).
ستجد:
- name: اسم الصيدلية (صيدلية د/ دعاء أحمد كمال)
- phone: رقم الهاتف للاتصال المباشر
- whatsapp: رقم واتساب بصيغة دولية (201090187051)
- prescriptionMsg: الرسالة التلقائية التي تظهر عند طلب روشتة عبر واتساب
- address: العنوان النصي
- mapsUrl: رابط موقع الصيدلية على Google Maps
- facebookUrl: رابط صفحة الفيسبوك
- instagramUrl: رابط حساب الإنستجرام
- payments.instapay: حساب ورابط إنستاباي
- payments.vodafoneCash: رقم محفظة فودافون كاش
- payments.etisalatCash: رقم ورابط محفظة اتصالات كاش
